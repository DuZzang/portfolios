# Portfolio

회계사시험에 합격하고 산업공학을 전공하고 있습니다. 회계·재무 전문성에 데이터와 AI를 접목해 기업의 문제를 이해하고 해결하는 데 관심이 있습니다.

## 프로젝트

### 금융공학 — 주식 포트폴리오 분석

**문제:** 수익률뿐 아니라 위험까지 고려해 포트폴리오를 비교하고, 평가에서 빠질 수 있는 상장폐지 수익률을 살펴봤습니다.

**내 역할:** 상장폐지 수익률 반영을 제안하고 자료를 제공했으며, 팀의 코드와 분석 흐름을 수정·통합하고 결과를 검토했습니다.

**결과:** 같은 종목군·동일가중·거래비용 조건에서 CNN 단독과 네 신호의 균등결합을 비교했을 때, 결합의 평균 수익률과 변동성은 낮고 샤프비율은 높게 관찰됐습니다. 같은 표본에서 전략을 선택한 만큼 독립 검증된 우위로 해석하지 않습니다.

팀 프로젝트이며 일부 코드와 문서 작성에 AI를 활용했습니다.

[IFE-Project 공개 코드 보기](https://github.com/DuZzang/IFE-Project-public) · 연구 데이터는 포함하지 않습니다.

### 산업공학 종합설계 — 3D 프린터 언더필 탐지

3D 프린터 출력 사진의 언더필 탐지와 적은 불량 데이터 보완을 연구하는 팀 프로젝트입니다. 연속 사진의 평가 누수 가능성을 제기하고 시간 블록 분할을 적용했으며, 팀에서 준비한 모델들을 가능한 범위에서 공통 평가 조건에 맞춰 테스트·비교했습니다. [프로젝트 소개 보기](projects/manufacturing-defect-ai.md) · [공개 코드 보기](https://github.com/DuZzang/manufacturing-defect-ai-public)
