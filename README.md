# Portfolio

회계·재무와 산업공학을 바탕으로 데이터와 AI를 활용해 문제를 이해하고 해결하는 과정에 관심이 있습니다.

## 프로젝트

### 금융공학 — 주식 포트폴리오 분석

CNN 기반 차트 신호와 금융 지표를 결합해 포트폴리오를 분석한 팀 프로젝트입니다. 상장폐지 수익률 반영 문제를 제시하고 데이터와 분석 흐름을 검토·통합했습니다. 팀원과 AI의 기여도 구분해 기록합니다.

[IFE-Project 저장소](https://github.com/DuZzang/IFE-Project) · 현재 비공개: 접근 권한이 있는 사용자만 볼 수 있습니다.

### 산업공학 종합설계 — 3D 프린터 언더필 탐지

3D 프린터 출력 사진을 활용해 정상·언더필 분류를 살펴보는 팀 연구입니다. 제한된 불량 데이터의 보완과 평가상의 한계를 함께 검토하고 있습니다. 프로젝트 저장소는 준비 중입니다.

## 관심 분야

회계·재무 실무, 산업·기업 분석, 데이터와 AI를 활용한 문제 해결에 관심이 있습니다.
