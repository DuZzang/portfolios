# 3D 프린터 언더필 탐지 연구

> 산업공학 종합설계 팀 프로젝트 · 진행 중

## 문제와 목적

3D 프린팅에서는 불량 사례를 충분히 확보하기 어려울 수 있습니다. 이 프로젝트는 출력 중 촬영한 사진을 활용해 언더필(재료가 부족하게 압출된 상태)을 탐지하고, **실제 불량 사진이 적을 때 생성 이미지로 학습 데이터를 보완해 검사 성능을 유지할 수 있는지** 살펴봅니다.

## 데이터와 범위

정상 출력 사진 2,000장과 언더필 출력 사진 2,000장을 사용합니다. 이 라벨은 **출력 조건**을 나타내므로, 모든 사진에 눈으로 확인할 수 있는 결함이 나타난다는 뜻은 아닙니다. 각 클래스가 하나의 출력에서 촬영됐기 때문에, 출력물이나 촬영 조건의 차이가 분류 단서로 작용할 가능성이 있습니다.

교수님의 자료 공개 제한에 따라 원본·가공·생성 이미지는 공개하지 않습니다.

## 연구 진행

- **9~10월:** 사진에서 판정에 필요한 영역을 살펴보고 전처리·선별 방법을 검토했습니다. 지도학습 분류와 정상 사진을 활용한 이상 탐지 등 여러 접근을 비교했으며, 연속 촬영 사진의 유사성을 고려한 시간 블록 분할도 사용했습니다.
- **11월:** 적은 실제 이미지로 생성 모델을 시험하고 이미지 품질을 살펴보는 예비 작업을 진행했습니다.

위 내용은 기존 프로젝트 기록에 근거한 진행 요약입니다. 최종 전처리, 모델과 전체 파이프라인은 아직 팀에서 확정하지 않았습니다.

## 현재 한계

- 생성 이미지를 분류기 학습에 보충했을 때 실제 검사 성능이 유지되는지는 아직 확인되지 않았습니다.
- 클래스별 출력이 1회이므로, 기존 사진을 시간 블록으로 나누어 평가하더라도 새로운 출력 실험에 대한 일반화 성능을 검증한 것은 아닙니다.
- 마스킹 영역이나 촬영 시점 등 결함 외의 차이를 모델이 판정 단서로 활용할 가능성이 있어 추가 검토가 필요합니다.
- 이 소개문은 기존 기록을 정리한 것이며 학습이나 결과를 새로 재현한 것은 아닙니다.

## 협업과 코드

전처리, 모델과 평가를 팀에서 나누어 검토하고 결과를 공유했습니다. 일부 코드·분석·정리 작업에는 생성형 AI의 도움을 받았으며, 결과와 한계는 별도로 확인하고 있습니다.

현재 공개된 프로젝트 코드는 없습니다. 데이터와 코드의 사용·공개 범위를 확인하면서 정리하고 있습니다.
